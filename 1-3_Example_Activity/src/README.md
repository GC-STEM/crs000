# Construct the Higher/Lower Game

The required deliverable is [`high_low.py`](high_low.py). Write your own
implementation using the [requirements](../docs/10_requirements.md) and
[construction guidance](../docs/30_construction.md).

Keep the provided import, `main()` wrapper, and main guard. No additional
functions or classes are required. Complete the module docstring in your own
words and acknowledge sources you use.

From the **repository root**:

```bash
python 1-3_Example_Activity/src/high_low.py
```

Use [the test plan](../docs/40_testing.md) to check your work.
Return to the [activity README](../README.md) for file roles and help.
