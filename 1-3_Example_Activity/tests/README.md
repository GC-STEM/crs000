# Test the Higher/Lower Game

Use the [test plan](../docs/40_testing.md) to check the required Python program.
The provided [automated checks](test_high_low.py) are learning tools, not a
grading system. Keep them unchanged during student work.

From the **repository root**:

```bash
python 1-3_Example_Activity/tests/test_high_low.py
```

The untouched starter is expected to fail. Checks cover selected input and
random-selection behavior; manually review prompts, feedback, validation, and
code quality as described in the plan. Record only results you actually observe.
