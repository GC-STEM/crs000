Welcome to the **CRS-000 Code Repository**! This repository supplements your [**Brightspace**](https://learn.snhu.edu/d2l/home) course with the files, instructions, and resources needed to complete **computing-related assignments**, such as programming, data analysis, and technical projects. Other course activities, including discussions, quizzes, and written assignments, remain in Brightspace.

**New to GitHub?** Don't worry if the folders and files look unfamiliar. Start with the [**Module 1 Setup Tasks**](#1-1-setup-tasks) below, which will guide you through setting up and using your own course repository. After setup, use the module activity link for your current week to open the activity’s README and find the files you’ll work with.

---

> [!CAUTION]
> Do **NOT** fork course code repositories! Forks are public and cannot be made private until they are disconnected from the original repository. If you already did, don't worry. The [**Setup Tasks**](https://github.com/GC-STEM/crs000/wiki/1%E2%80%901-Setup-Tasks) will show you how to unfork it and continue setting up your private course repository.

## Help and Support

### AI Support

[**GitHub Copilot**](https://github.com/copilot) is an AI assistant that can help you understand activity instructions, explain technical concepts and errors, and review your work. You can use Copilot on GitHub.com or in Visual Studio Code (VS Code) on your computer.

**Getting help with Copilot:**

- **On GitHub.com:** Open Copilot Chat, select your course repository as context, and ask a question about an activity or file. You can also open a repository file and select the Copilot icon to ask about it.
- **In VS Code:** Open your course repository, sign in to GitHub, and open Copilot Chat. Select the **Course Mentor** from the agent menu, if available. This course-specific assistant is designed to explain concepts, provide feedback, and help you troubleshoot without completing your assignments.

**In VS Code, with Course Mentor agent selected, type `/` in Copilot Chat and choose:**

- `/understand-activity` — Understand an activity's instructions.
- `/debug-my-attempt` — Investigate an error in your own work.
- `/review-my-work` — Get feedback on your existing attempt.
- `/draft-support-post` — Prepare a GitHub Issue or Discussion for your review.

Add your question and relevant details after the command. If these commands
are unavailable, ask Course Mentor a question in ordinary language instead.
On GitHub.com, use ordinary questions; VS Code commands may not be available.

> [!IMPORTANT]
> **AI is a learning assistant, not a substitute for your own work.** You are responsible for completing your assignments, checking AI responses, and following your course's AI-use rules. Do not share passwords, personal information, or private course records with AI tools.

Read [**AI Use and Course Mentor**](https://github.com/GC-STEM/crs000/wiki/AI-USE.md) for permitted uses, restrictions, and additional guidance.
