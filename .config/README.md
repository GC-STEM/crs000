# Configuration Files (`.config/`)

---

> [!CAUTION]
> **Do not modify, rename, or delete files in this folder.** These files contain settings used to configure and verify your course computing environment. Changing them may cause setup, testing, or other automated tools to fail. If you accidentally change or delete files in this folder, see the [Restore Accidentally Changed Files](#restore-accidentally-changed-files).

## Purpose

The `.config/` folder stores configuration files that help keep computing environments consistent across course repositories.

These files define or support the tools, dependencies, and settings needed for course activities. They are generally maintained by GC-STEM rather than individual students.

GC-STEM uses two levels of computing environment configuration:

- **Standard Operating Environment (SOE):** Common development tools and settings shared across STEM courses. Defined in the [GC-STEM/SOE](https://github.com/GC-STEM/SOE) repository.
- **Course-Specific Overlay (CSO):** Additional tools and settings required for a particular course, beyond those provided by the SOE.

Configuration folders commonly contain JSON manifest files (`*_manifest.json`), Python dependency lists (`requirements*.txt`), and other files used by setup or automation scripts. The exact contents depend on the repository.

## Folder Contents

### `cso_manifest.json`

The **Course-Specific Overlay (CSO) manifest** describes the course's computing environment.

It identifies the course, references its shared SOE baseline, and defines any additional or overridden environment settings needed by the course.

Setup and verification tools can use this information to help provide consistent computing environments.

**Student action:** None. Do not edit this file.

### `requirements.txt`

Lists Python packages used to support development activities.

The current template includes:

- **Ruff:** Checks Python code for common problems and formatting issues.
- **pytest:** Runs automated Python tests.
- **pytest-cov:** Measures which parts of Python code are exercised by tests.

Your course setup instructions explain how to install or use the required tools.

**Student action:** Follow your course setup instructions. Do not edit this file.

### `README.md`

This document explains the purpose of the `.config/` folder and its contents.

**Student action:** Read for reference. No changes are needed.

## Help and Support

If you encounter configuration errors, follow your course's [Setup Tasks](https://github.com/GC-STEM/crs000/wiki/1%E2%80%901-Setup-Tasks) or contact your instructor. Do not attempt to fix configuration problems by changing these files unless instructed to do so.

### Restore Accidentally Changed Files

If you accidentally change or delete files in `.config/`, open a terminal in your course repository's root folder and run:

```shell
git fetch upstream main && git restore --source=upstream/main --staged --worktree -- .config/
```

This restores the original tracked files from your course's master repository, including deleted files. **Any changes you made to those files will be lost.** Files you added yourself will not be deleted.

This command assumes you completed the course setup tasks and configured the `upstream` Git remote. If the command fails, ask your instructor for help.
